# logistics-performance-dashboard
ABOUT: 
Power BI dashboard on logistics performance of a consumer-goods industry brand, highlighting ability in ETL and data visualization.

1. Download "Portfolio Dashboard.xlsx" to have a copy of the dataset.
2. Download "Danan_PortfolioReport.pbix" and open with Power BI desktop to have your own copy of my visualizations.
3. Feel free to navigate using the slicers on top as you would like.

DISCLAIMER:
This is more of a showcase of my dashboarding capabilities only rather than a showcase of my actual analysis skills.
